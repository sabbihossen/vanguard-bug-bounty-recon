# 🛡️ Vanguard VDP Reconnaissance

### External Attack Surface Discovery | Web Security Research

A documented reconnaissance project covering subdomain discovery, live-host verification, technology fingerprinting, directory discovery, and URL collection as part of a practical cybersecurity exercise.

> **Purpose:** Security education, authorized reconnaissance, and evidence-based documentation.

---

## 📊 Project Metrics

| Metric | Reported Result |
|---|---:|
| Unique subdomains discovered | 4,343 |
| Live hosts identified | 1,110 |
| Unique URLs collected | 4,705 |

*Metrics are based on the original assignment notes and should be supported by the available evidence.*

## 🎯 Project Objectives

- Map the externally observable attack surface.
- Identify and organize subdomain candidates.
- Verify host availability using permitted methods.
- Identify observable web technologies and infrastructure.
- Discover potentially relevant directories and URLs.
- Document observations, limitations, and responsible disclosure considerations.

## ⚙️ Methodology

1. Scope verification
2. Subdomain discovery
3. Live-host verification
4. Technology fingerprinting
5. Directory and content discovery
6. URL and endpoint collection
7. Results review and documentation
